# Практики инженерных MCP и решения FASTMEAN MCP

При подготовке версии 1.0.0 сравнивались первичные исходники двух работающих проектов. Это сравнение архитектурных приёмов, без заимствования их кода и без заявления о совместимости с их протоколами.

| Проект и первичный источник | Применённый принцип |
|---|---|
| [Blender MCP: server.py](https://github.com/ahujasid/mcp-for-blender/blob/main/src/blender_mcp/server.py) | Общие инструкции сервера, обнаружение возможностей, изображения в ответах и ResourceLink на зарегистрированные результаты. |
| [FreeCAD MCP: execution](https://github.com/neka-nat/freecad-mcp/blob/main/docs/execution.md) и [server.py](https://github.com/neka-nat/freecad-mcp/blob/main/src/freecad_mcp/server.py) | Различать GUI и рабочий процесс, сообщать состояние и ошибку долгой операции, сохранять идентификатор задания. |

Из первоначального аудита в FASTMEAN MCP вошли пять ограниченных изменений:

1. Ограниченные JSON-ответы и preview строк; полный результат остаётся файлом задания. Инспекция не возвращает все native objects без явного запроса.
2. Активные operation_id, таймаут и адресная отмена собственных нативных процессов. Это инструменты сервера; расширение MCP Tasks не объявляется.
3. Сохраняемые результаты, каталог MIME/размеров/хешей, MCP-ресурсы и постраничное чтение CSV. Произвольный путь не становится файловым API.
4. Python-пакет с console entry point и включённой справкой, Python installer/doctor/uninstall с сохранением чужих настроек Codex.
5. Явные лимиты signals и числовых параметров, отдельная проверка установки, ожидаемые ошибки запросов через MCP isError.

Для схем дополнительно важна визуальная проверка. Генератор создаёт реальные провода и junctions; PNG/SVG preview позволяет проверить размещение до открытия FASTMEAN. В Point75A сохранены 25 опубликованных R/L/C, а четыре компонента стенда обозначены отдельно. Рисунок preview и график по нативным данным имеют указанное происхождение.

Проверки протокола, границ файлов, компоновки и нативного RC-примера находятся в tests. CI без FASTMEAN проверяет переносимую часть; нативный результат проверяется отдельно на Windows. Наличие функций и тестов не означает прохождения ещё не запущенного CI или поддержки всех моделей FASTMEAN.
